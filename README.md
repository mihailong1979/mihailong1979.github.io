А также Состояния сознания и их нейробиологические корреляты:
1. Ощущение "божественного присутствия" - Религиозное переживание. Активные зоны DMN: Правая височная доля (активация), TPJ (теменно-височный стык) - гипоактивность. Префронтальная кора - снижение активности. Нейрохимия: Серотонин ↑ (повышение), Дофамин ↓ (снижение).
2. Ощущение "вне тела" - Внекорпоральное состояние. Активные зоны DMN: TPJ (теменно-височный стык) - дисфункция, Префронтальная кора - снижение активности. Теменная доля - повышение активности. Нейрохимия: Глутамат ↓ (снижение), ГАМК ↑ (повышение). Результат: Ощущение "вне тела" (на основе экспериментов Олафа Бланке, 2002)
3. Творческое озарение. Активные зоны DMN: Правая височная доля - повышение активности. Префронтальная кора - снижение активности. Лимбическая система - повышение активности. Нейрохимия: Дофамин ↑↑ (значительное повышение), Норадреналин ↑ (повышение). Результат: "Аха-момент", появление новой идеи (аналогично состоянию сценаристов при вдохновении)

Ключевые сокращения:

DMN (Default Mode Network) - дефолтная режимная сеть мозга
TPJ (Temporo-Parietal Junction) - теменно-височный стык

Измерения ритмов мозга производится с помощью датчика TGAM/EEG.
